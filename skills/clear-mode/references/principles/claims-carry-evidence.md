# Claims carry evidence

Pillar: observation

**Rule.** Every "done", "works", "fixed" or "verified" names the command, output or artifact that shows it. A claim without evidence is labelled as inference.

**Applies when.** Writing any reply, report, commit message, or `record end`.

**Changes.** You write "`npm test -- feed` passes, 14 tests" instead of "tests pass", and "not run on Android" instead of leaving Android out. Confirmed evidence and inference sit under separate headings when both appear.

**Counter-example.** "Verified the fix works" after reading the diff and reasoning that it should.
